# Advanced IAM features
{: #advanced-features}

{{site.data.keyword.cloud}} Identity and Access Management (IAM) provides advanced features that enable you to implement layered security architectures and defense in depth strategies to reduce your attack surface.
{: shortdesc}

## Service to service authorizations
{: #service-authorizations-feature}

In a scenario that you need to provide one service access to another, you can create a policy by using a service to service authorization. For more information, see [Using authorizations to grant access between services](/docs/iam?topic=iam-serviceauth).

## Related access management controls
{: #related-access-feature}

IAM is the foundation for standards-based identity and access management in {{site.data.keyword.cloud_notm}}, but you can extend your security strategy by building layered security architectures. Build on IAM access controls with context-based restrictions to implement defense in depth and reduce your attack surface. These restrictions work with traditional IAM policies, which are based on identity, to provide an additional layer of protection. See [What are context-based restrictions?](/docs/iam?topic=iam-context-restrictions-whatis) for more information.
